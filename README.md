# ml-inference-architectures
This repository contains examples of difference inference architectures for machine learning models.

| # | Architecture | Description |
|---|--------------|-------------|
| 1 | [ML Serverless Inference](1.ML-Serverless-Inference) | Lambda container image serving a scikit-learn model from S3 behind an HTTP API |
| 2 | [ML Training Pipeline](2.ML-Training-Pipeline) | SageMaker Pipeline triggered by an S3 upload: train, evaluate, threshold gate, manual approval, deploy to a SageMaker Serverless endpoint |
