1

Upload data

An engineer uploads a CSV to data/train/ in the training bucket. The fixed holdout set lives in data/test/.

2

Trigger

S3 sends Object Created to EventBridge. The rule only matches data/train/*.csv, so test uploads never start a run.

3

Start pipeline

startPipeline calls StartPipelineExecution with the file URI and thresholds. It's idempotent per upload and fire-and-forget.

4

Preprocess & train

One ml.t3.medium processing job validates the data, fits the scikit-learn pipeline and writes model.tar.gz. (Temporary: a separate Training job once quota allows.)

5

Evaluate & gate

Evaluate scores the fixed holdout set. CheckMetrics needs R² ≥ 0.80 and RMSE ≤ 3.5; otherwise the Fail step ends the run.

6

Register & notify

A passing model becomes a new version in the Model Registry as PendingManualApproval. EventBridge sends an SNS email to the approver. Failures are emailed too.

7

Manual approval

The approver reviews the metrics and sets the version to Approved. Rejected deploys nothing.

8

Deploy

The approval event invokes deployModel, which creates a model and serverless config, then creates or updates the endpoint with no downtime.

9

Inference

Clients call InvokeEndpoint with JSON and get predicted_mpg back. The endpoint scales to zero, so it costs nothing while idle.

10

Ops & CI/CD

Failed events are retried, then parked in SQS. Logs go to CloudWatch. GitHub Actions (OIDC) runs sls deploy and build_pipeline.py.
